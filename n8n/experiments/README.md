# n8n Experiments

이 디렉토리는 n8n workflow의 실험안, 튜닝본, 설계 초안을 보관합니다.

## 용도
- 새 workflow 설계 초안
- 기존 workflow의 튜닝 버전
- 운영 반영 전 비교/검토용 JSON
- 설계용 메모 또는 중간 결과물

## 규칙
- 여기 있는 파일은 운영 기준본이 아닙니다.
- 운영 반영이 끝난 결과만 `../workflows/`로 승격합니다.
- 운영 맥락/주의사항은 `../notes/`에 기록합니다.

## 네이밍 가이드
- `*-design.md` : 설계 문서
- `*-tuned.json` : 튜닝/개선 실험본
- `*-candidate.json` 또는 비교 가능한 별도 이름 : 검토 중인 후보안
